# Customer-Shopping-Data-Analysis
This project analyzes customer shopping data using Python, Pandas, and Matplotlib. It includes data cleaning, exploratory data analysis, and visualizations to identify customer behavior, sales trends, and payment preferences, providing valuable insights for business decision-making.
# Customer Shopping Data Analysis

## Project Overview
This project focuses on analyzing customer shopping data to understand purchasing behavior, sales trends, and payment preferences. The analysis was carried out using Python, Pandas, and Matplotlib. Through data cleaning, exploration, and visualization, meaningful insights were generated from the retail dataset to support better business decision-making.

## Objectives
- Analyze customer shopping behavior.
- Identify sales trends across product categories.
- Understand customer payment preferences.
- Perform data cleaning and preprocessing.
- Create visualizations for better understanding of the data.
- Generate useful business insights from the dataset.

## Dataset Description
The Customer Shopping Data dataset contains information related to customer purchases made in shopping malls. It includes details such as customer demographics, product categories, payment methods, quantities purchased, and transaction values. The dataset is used to perform exploratory data analysis and discover shopping patterns.

## Tools and Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Data Analysis Process

### 1. Data Loading
The dataset was imported into Google Colab using Pandas and examined to understand its structure.

### 2. Data Understanding
Basic information such as columns, data types, and dataset dimensions were explored.

### 3. Data Cleaning
The dataset was checked for missing values and duplicate records to ensure data quality.

### 4. Exploratory Data Analysis (EDA)
Several analyses were performed to identify trends and patterns in customer purchases.

### 5. Data Visualization
Different charts were created to visualize sales distribution, payment methods, and customer demographics.

## Visualizations
- Sales by Category (Bar Chart)
- Payment Method Distribution (Pie Chart)
- Gender Distribution (Bar Chart)

## Key Findings
- Different product categories contribute differently to overall sales.
- Customers use multiple payment methods, with some methods being more popular than others.
- Both male and female customers actively participate in shopping activities.
- The dataset was clean and suitable for analysis after verification.
- Visualizations helped identify important shopping trends and customer preferences.

## Conclusion
This project successfully analyzed customer shopping data using Python-based data analysis techniques. Data cleaning, exploratory data analysis, and visualizations provided valuable insights into customer behavior, purchasing patterns, and payment preferences. The results can help businesses make informed decisions and improve customer satisfaction.
